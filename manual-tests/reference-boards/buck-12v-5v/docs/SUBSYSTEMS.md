# Subsystems

## Input

12V input header with bulk and ceramic decoupling, plus the enable divider that
sets the converter's input undervoltage lockout near 10V.

## Converter

TPS54560B step-down converter: bootstrap capacitor, frequency-setting resistor,
type-II compensation network, Schottky catch diode, and the power inductor.

## Output

5V output bank: ceramic output capacitors, feedback divider with feedforward
capacitor, rail indicator LED, and the load header.
