# Stage4 schematic pinout

Canonical connectivity is schematic.intent.json; the schematic is generated only by draft_schematic. All39 BOM parts, Values and footprints are retained. ASSUMED net names implement the documented Stage3 interfaces; U_A means adapter TX before R14, U_T means MCU TX before U5. The U_ prefix denotes the UART family: U_A adapter TX, U_T MCU TX, U_RX MCU RX, U_IN/U_OUT buffer nodes and U_ARX adapter RX. The initial UART_ shortening still collided; shortening the entire family reduces text width consistently. Rationale: readable labels with explicit endpoint meanings and unchanged connectivity.

## Intentional no-connects and omissions

U1 noConnect:4,6,7,9,10,12,13,15,16,17,24,25,26,27,28,29,32,33,34,35. These cover all manufacturer NC endpoints and unused GPIO0/1/3/10/18/19. U6 noConnect:1,2, as its manufacturer permits floating NCs. Rationale: declare every unused package endpoint explicitly; no USB data or extra peripheral loading is intended.

No power LED, UART power contact, onboard OLED footprint, USB data/PD circuit, TPS2553 or external fixed-buck feedback divider is added. Rationale: preserve power margin, source restrictions, buffered programming and external display architecture; TPS259533 intentionally replaces TPS2553, and TI recommends fixed-output FB grounded.
