# RFC 11 layout record schemas

Vendored unchanged from `schemas/rfc11/` in
[copperheadhq/copperhead-rfcs](https://github.com/copperheadhq/copperhead-rfcs),
pull request #15 (RFC 11 version 1.4), at commit `c712696`.

These schemas define the records, and the TypeScript types in
`../../types.generated.ts` are generated from them by
`scripts/gen-pcb-ir-types.ts`. Do not edit them here. Change them in the RFC
repository, copy them again, and regenerate.
